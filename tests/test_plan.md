
This document describes the tests used to check the functionality of the Mini Shell program.

 Basic Shell Tests

 Test | Command | Expected Result 

 Start shell | ./msh | Shell displays welcome message and prompt 
 Display help | help | Displays available built-in commands 
 Exit shell | exit | Shell terminates 
 Empty input | Press Enter | Shell displays another prompt

These tests help verify that the Mini Shell correctly handles built-in commands, external commands, directory changes, and command exit statuses.
